# Cadrage et conception

Les documents produits avant le développement : ce que l'entreprise veut, et comment le projet y répond.

| Dossier | Contenu |
|---|---|
| `01_cadrage_besoins_metier` | Présentation de l'entreprise, note de cadrage, étude de l'existant, besoins métier, cahier des charges, business case |
| `02_organisation_pilotage` | Plan de management, registre de suivi, classeur de pilotage |
| `03_analyse_preparation_donnees` | Cartographie des relations, audit qualité, plan d'intégration des sources |
| `04_gouvernance_donnees` | Référentiel des données et KPI, règles qualité, lignage, modèles conceptuel et relationnel |
| `05_conception_technique` | Architecture, modèle dimensionnel, ERD de chaque base, mapping source-cible, spécifications ETL |
| `06_specifications_bi_data_science` | Besoins analytiques, catalogue des mesures DAX, maquettes, cadrage data science |

Les fichiers `.drawio` s'ouvrent avec [draw.io](https://app.diagrams.net) ; leurs images sont dans les dossiers `PNG/`, `png/` et `svg/`.
