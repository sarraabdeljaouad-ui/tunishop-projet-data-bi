# Plateforme de recherche vue 360

Une plateforme de recherche floue sur les clients, produits, fournisseurs, commandes et transporteurs,
avec une fiche 360 par entité : chiffres clés, prédictions expliquées, historique et avis.

Elle existe en deux versions. Le code est dans deux dépôts séparés ; ce dossier rassemble la conception,
les maquettes et la recette.

| Version | En ligne | Code |
|---|---|---|
| Streamlit | [tunishopsarraapps.streamlit.app](https://tunishopsarraapps.streamlit.app) | [tunishop-plateforme-360](https://github.com/sarraabdeljaouad-ui/tunishop-plateforme-360) |
| HTML statique (GitHub Pages) | LIEN À COMPLÉTER | [tunishop-plateforme-360-web](https://github.com/sarraabdeljaouad-ui/tunishop-plateforme-360-web) |

## Contenu de ce dossier

| Dossier | Contenu |
|---|---|
| `conception/` | Organisation générale (ce que chaque page affiche) et note de conception de la version HTML |
| `maquettes/` | Maquettes des 9 écrans et leur explication |
| `inventaire_donnees/` | Sources utilisées : vues du DWH et de TuniShop_ANALYTICS (Streamlit), exports JSON (version HTML) |
| `validation_streamlit/` | Note de conception, cahier de recette, rapport de recette, PV, rapport de phase |
| `captures_streamlit/` | Captures de la plateforme Streamlit |
| `validation_html/` | Recette de la version HTML (même circuit de 4 documents) — à venir |
| `captures_html/` | Captures du site publié — à venir |

La version HTML suit le même circuit de recette que Streamlit : note de conception, cahier de recette,
rapport de recette et procès-verbal. Ces documents seront ajoutés dans `validation_html/` quand la recette sera faite.
